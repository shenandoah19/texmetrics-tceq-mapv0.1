TexMetrics — TCEQ Agreed Orders map
===================================

This folder is ready to upload to GitHub Pages. You do not need
to install anything or run any commands.

WHAT SHOULD BE IN THIS FOLDER
- index.html      (full page)
- embed.html      (use this URL inside Framer)
- app.js
- styles.css
- .nojekyll
- data/tceq-orders.json

GITHUB (website only — no Terminal)
1. Go to https://github.com and sign in.
2. Click the + in the top right → New repository.
3. Repository name: texmetrics-tceq-map
4. Public → Create repository.
5. On the empty-repo page, click “uploading an existing file”.
6. Drag EVERY FILE AND THE data FOLDER from this unzipped
   folder onto GitHub. Do not drag the outer wrapper folder.
   You should see index.html at the top of the file list.
7. Scroll down → Commit changes.
8. Click Settings → Pages (left sidebar).
9. Under Build and deployment:
     Source: Deploy from a branch
     Branch: main
     Folder: / (root)
   Click Save.
10. Wait one or two minutes, then refresh. GitHub will show
    a URL like:
      https://YOURNAME.github.io/texmetrics-tceq-map/
11. Also open:
      https://YOURNAME.github.io/texmetrics-tceq-map/embed.html
    That is the Framer URL.

FRAMER (TexMetrics.com)
1. Open your TexMetrics site in Framer.
2. Make a new page (example: /agreed-orders) or pick the page
   where the map should live.
3. Insert → Embed.
4. Paste the embed.html URL from step 11.
5. Set the embed height to about 780.
6. Publish the Framer site.

If the map is blank after upload, you probably uploaded the
wrapper folder. Delete the repo files and upload the contents
so index.html sits at the root.
